# Сервис управления фотостудией

## Назначение

Приложение для управления фотостудией: позволяет клиентам просматривать 
доступные залы и бронировать их на нужное время, а администрации — 
управлять студиями, залами и расписанием бронирований.

## Целевая аудитория

- Клиенты (фотографы, модели, частные пользователи), которым нужно 
  арендовать зал для съёмки
- Администраторы фотостудий, управляющие залами и бронированиями
- Владельцы студий, которым нужен учёт загрузки залов

## Предметная область

Аренда помещений для фотосъёмок. Студия содержит несколько залов 
с разными характеристиками (площадь, интерьер, оборудование). 
Клиент выбирает зал и время, система проверяет доступность 
и оформляет бронирование.

## Основные сущности

- Студия — фотостудия с названием и адресом
- Зал — помещение внутри студии (площадь, цена за час, вместимость)
- Клиент — пользователь, оформляющий бронирование
- Бронирование — запись клиента на зал на конкретную дату и время

## Основные функции

- Просмотр информации о студии и её залах
- Проверка доступности зала на выбранную дату
- Расчёт стоимости бронирования с учётом скидок
- Определение статуса клиента (новый / постоянный / VIP)
- Оформление бронирования (будет расширено на ПР2)

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django
- подключение базы данных (PostgreSQL)
- реализация пользователей и аутентификации
- разработка REST API для бронирования
- контейнеризация приложения (Docker)
- настройка CI/CD
- автоматизированное тестирование (Pytest)
